# D1 Mini Matriz de LEDS 8x8

Criar um projeto Arduino/ESP8266 para a placa **WEMOS D1 Mini (ESP8266MOD)** com o **Matrix LED Shield 8x8 (TM1640)**.

Conectar o D1 Mini à rede wi-fi S729-1 com senha 25102026.

Acessar data e hora online. Exibir data e hora na matriz 8x8 como uma mensagem circular (moving message).
